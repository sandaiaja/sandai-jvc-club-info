# 三大小ジュニアバレーボールクラブ クラブ案内

入部をご検討の方・クラブにご関心のある方向けの公開案内ページです。
GitHub Pages で配信しています。

## ファイル構成

- `index.html` — 案内ページ本体
- `sandai-junior-club-guide.pdf` — クラブ案内資料

## 資料の更新方法

1. 新しい PDF を `sandai-junior-club-guide.pdf` という名前で上書き
2. `git add . && git commit -m "資料を更新" && git push`
3. 数分で GitHub Pages に反映されます
